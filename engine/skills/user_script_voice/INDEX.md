## How to read this

Each row points to a snapshot in the per-job `script_history/` directory. The naming convention:
- `round_NNN_agent.md` — what the agent surfaced (the dialogue block from that round)
- `round_NNN_user.md` — what the user pasted back, with their edits

Compare consecutive rounds (round_NNN_agent.md → round_(NNN+1)_user.md) to see what the user changed and why. Patterns that emerge from these diffs land in PATTERNS.md.
