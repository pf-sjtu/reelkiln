## 2. 平台覆盖说明（同一份代码，三平台）

- `port` 测试在三平台上跑同一套用例。为让 Windows/macOS 真正覆盖各自分支而不是“模拟 linux”：
  - `BootstrapCore.runAll` 步骤机测试与 shim 幂等测试使用**宿主平台**（Windows 上即覆盖 `uv.exe` 复制、`%SystemRoot%\System32\tar.exe` 解包、`npm.cmd`、`Path` 键、`.cmd` shim）；
  - 依赖 POSIX 的断言显式跳过并注明原因：文件模式位（NTFS 无 POSIX 位）、与原版 sh 脚本 / GNU `stat` 的差分（仅 Linux）、`sh` 桩 python 的 money 兼容测试（win32 跳过）；
  - macOS 上 `tmpdir()` 的 `/private/var` 符号链接用 `realpathSync` 归一。
- `engine-static` 在 Windows 上运行 `WindowsReal` 用例（真实 `msvcrt` 锁跨进程冲突、`taskkill /T` 杀孙进程）与 `_compat_dirfd` 模拟路径差分；在 Linux/macOS 上运行 POSIX 用例。
- 行尾：`.gitattributes` 设 `* text=auto eol=lf`。Windows runner 默认 `core.autocrlf=true`，首跑时以 CRLF 检出导致 `gen-verbatim` 行锚点 `/^}$/` 失配；现所有文本均以 LF 检出，`engine/**`、`bootstrap/**` 仍为 `-text`（逐字节）。

## 3. 运行记录（2026-10-20，UTC+8）

首轮各平台暴露并已修复的问题（全部是测试/环境问题，被测代码只有一处真实修复）：

| 平台 / 作业 | 现象 | 修复 |
|---|---|---|
| windows engine-static | POSIX 专属用例在 nt 上运行失败；dirfd 差分用 `str(Path)` 比较（反斜杠） | `skipUnless(posix)`；新增 `WindowsReal`；`as_posix()` |
| macos engine-static | `errno.EDEADLOCK` 不存在 | **代码修复**：`_compat_lock` 用 `getattr(errno, "EDEADLOCK", errno.EDEADLK)` |
| macos port | `/private/var` realpath；HOME；GNU stat 差分 | 归一 / 补 HOME / 仅 Linux |
| ubuntu port | 两个用例 “Promise resolution still pending” 被取消 | mock 子进程发 `close` 并保持事件循环 |
| windows port | CRLF 检出导致生成器失败；linux 模拟用例混用 Windows 路径；`tar.exe` 未被记录型 runner 转发；NTFS 模式位 | `.gitattributes` LF + 生成器容忍 `\r\n`；宿主平台；转发 `System32\tar.exe`；跳过模式位 |
| linux-baseline | Electron userData 落在 `$XDG_CONFIG_HOME`（runner 导出了该变量）而非 `$HOME/.config`，冒烟脚本找不到 `engine-current.json` | 冒烟脚本同时固定 `XDG_CONFIG_HOME` |
| windows-runbook | chocolatey 的 `ffmpeg.exe` 是相对路径 shim，复制到 bootstrap 后失效 | 改用 `lib\ffmpeg\tools\ffmpeg\bin` 下的真实二进制（ffmpeg 9.0.2） |

## 5. 本地复现

```bash
# port（任一平台）
cd port && npm ci && npm run gen && git diff --exit-code -- src && npm run build && npm test
# engine compat
python tools/test_engine_compat.py && python tools/engine_import_smoke.py both && python tools/check_lock_windows.py
# Linux 基线 + Electron 冒烟（需要 uv / ffmpeg / xvfb-run / node；联网）
OUT=/tmp/linux-run bash tools/linux_baseline.sh /tmp/vc && bash tools/linux_shell_smoke.sh /tmp/vc/bootstrap
# Windows（Git Bash；需要 node / python / uv / ffmpeg 在 PATH）
OUT=C:/vc/out bash tools/windows_runbook.sh C:/vc/run
```
